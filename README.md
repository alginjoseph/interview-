## 📖 array_methods.js

Covers all major JavaScript Array methods with clear comments and expected outputs:

### Mutating Methods
- `push()`, `pop()`, `shift()`, `unshift()`
- `splice()`, `sort()`, `reverse()`, `fill()`, `copyWithin()`

### Non-Mutating Methods
- `map()`, `filter()`, `reduce()`, `forEach()`
- `find()`, `findIndex()`, `some()`, `every()`
- `includes()`, `indexOf()`, `lastIndexOf()`
- `slice()`, `concat()`, `join()`
- `flat()`, `flatMap()`
- `at()` *(ES2022)*
- `toSorted()`, `toReversed()` *(ES2023)*

### Static Methods
- `Array.from()`, `Array.isArray()`, `Array.of()`

### Iterator Methods
- `entries()`, `keys()`, `values()`

### Common Interview Patterns
1. Method chaining
2. Remove duplicates with `Set`
3. Find max/min using `reduce()`
4. Deep flatten with `flat(Infinity)`
5. Partition array into two groups
6. Zip two arrays together
7. Chunk array into groups
8. Intersection of two arrays
9. Difference of two arrays
10. Transpose a matrix
